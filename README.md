# Cafe-Ordering-App
A mobile café ordering application developed using **Kotlin** and **Android Studio**, designed to streamline the ordering process for customers and improve efficiency for cafés. The app allows users to browse menus, customize items, place orders, and track order status in real time with a smooth and intuitive UI.

---

## Features
-**User Authentication**: Secure sign-up and login for customers.

-**Interactive Menu**: Displays categorized food and drink items with images, descriptions, and prices.

-**Customizable Orders**: Users can customize drinks or meals (size, add-ons, sugar level, etc.).

-**Cart & Checkout**: Add items to a cart, view order summary, and confirm orders easily.

-**Order Tracking**: Real-time order status updates from preparation to completion.

-**Favorites & History**: Save favorite items and view past orders for quick re-ordering.

-**Responsive UI**: Clean and modern interface following Material Design guidelines.

## Technologies Used

- Kotlin
- Android Studio
- Firebase Authentication
- FireStore (Firebase)
